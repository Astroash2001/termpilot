How TermPilot works
RUN
The status capsule
The black capsule at the top shows the state: Running with a live timer and a wave that moves with the output, then Done with a chime once the shell is back at its prompt. Below it is what you last sent. If your phone is locked when a run ends, you get a notification.
Voice prompts
Tap the mic and speak. Your words are added to whatever is already in the prompt box.
History and menus
Swipe across the prompt box to recall past prompts. The up and down keys move through menus in the terminal, or through history while you are typing.
40+ Antigravity commands
Type / or tap / CMD to search /plan, /goal, /mcp, /skills and the rest.
Pinned commands
One tap runs git status, git diff and the rest. + Pin saves your own.
Key row
^C interrupts, ESC leaves a menu, CLR clears the screen. Long-press the terminal to copy text.
Copied
Copy terminal text
or long-press to select
